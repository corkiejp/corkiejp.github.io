SuperValu Leaflet Viewer

What it does

This extension opens an overlay on SuperValu leaflet pages so you can browse page images, jump to a page number, move between leaflet editions, copy image URLs, and open the full PDF.

How to use

  1. Open a supported SuperValu leaflet page.
  2. Click the extension icon to open the overlay.
  3. Use the toolbar buttons or keyboard shortcuts to browse and download.

Keyboard shortcuts

  • ← Previous page image
  • → Next page image
  • G Focus jump box
  • Enter Go to page number
  • C Copy current image URL
  • O Open current image
  • D Download current image
  • P Download full PDF
  • [ Previous leaflet
  • ] Next leaflet
  • I Open this instructions page
  • Esc Close overlay

Automatic new-leaflet checks

Optionally, the extension can periodically check for a newer leaflet while your browser is running.

Notes

  • The page jump box works best after the leaflet pages have been detected.
  • If the page structure changes, use Rescan.
  • If a next leaflet is not live yet, the extension stays on the current page.
  • Reset stored leaflet history clears saved leaflet detection state, but keeps your auto-check and cadence settings.
