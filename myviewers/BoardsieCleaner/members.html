BoardsCleaner

Membership and feature controls

Boards.ie Cleaner has a small set of features reserved for users who support the site, such as removing ads, hiding warning banners, and automatically handling the privacy dialog.

How membership activation works

1. Detect from your Boards profile (recommended)

Open any Boards page and click the BoardsCleaner settings button 🍪 on the right hand side of the page. In the Membership Activation section:

  • Click Detect membership from my Boards profile.
  • A new tab opens to your Boards profile discussions page.
  • BoardsCleaner checks your status and, if you are a paid member, activates member features.

2. Fallback activation code

If automatic detection fails, you can use a one time activation code (See Member subbed forums for code or PM 'corkie'):

  • Enter the code in the Activation code box in the settings modal.
  • Click Activate.
  • If the code is valid, member features are enabled on this browser profile.

The activation code is stored only in your browser’s extension storage and can be reset at any time from the Danger zone section in the settings modal.

What the settings do

Overlay settings

  • Overlay delay (seconds) – how long the full page “Boards.ie Cleaner” overlay is shown while the page loads, to hide layout bounce.
  • Overlay message – the text shown on that overlay, useful to remind yourself which browser/device you’re on.

Members only features

  • Remove ads – removes known ad containers from Boards pages, so the layout is cleaner.
  • Remove alerts – removes warning / subscription banners (e.g. DismissMessage alerts) from the page.
  • Privacy dialog – auto click “DISAGREE” – when the Quantcast privacy dialog appears, BoardsCleaner will automatically click the DISAGREE button for you, so you can continue browsing without interacting every time.
  • CMP block – currently disabled for Boards.ie. The site expects the privacy dialog to be answered; fully blocking it can interfere with normal behaviour.

Danger zone

The Deactivate membership and reset features button:

  • Turns off membership for this browser profile.
  • Resets all settings (overlay delay/message and member feature toggles) back to safe defaults.
  • Does not remove the extension; you can reactivate later using your profile or activation code.

Boards.ie Cleaner does not send any of your Boards content, cookies, or activation codes to a third party server. All data is stored locally in your browser’s extension storage.
