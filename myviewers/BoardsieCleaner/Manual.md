# Boards.ie Cleaner V2 Manual

Boards.ie Cleaner V2 is a browser extension for cleaning up and customising the Boards.ie experience. It includes forum-specific theming, user options, backup tools, content enhancements, and member-focused features.

---

## What the extension does

Boards.ie Cleaner adds a set of quality-of-life improvements for Boards.ie users. Depending on your settings and enabled features, it can:

- clean up parts of the interface
- apply custom forum themes
- load built-in presets
- layer custom CSS on top of presets
- provide helper tools around posting and page interaction
- expose member-focused features through the Members Area
- store your settings in browser extension storage

Some features are always site-specific to Boards.ie, while others are enabled or adjusted through the options page.

---

## Options page

To open the options page:

1. Click the extension icon in your browser toolbar
2. Open **Extension Options**

The options page includes several sections:

- Global settings
- Preset shortcuts
- Forum theme editor
- Backup and restore
- Members Area

---

## Global settings

The global settings section controls whether the theme system is active.

### Enable forum themes

Turn this on to allow Boards.ie Cleaner to apply saved forum themes.

If this is off, no forum theme CSS is injected, even if you already have saved forum configurations.

### Allow built-in preset themes

Turn this on if you want to use preset theme files supplied with the extension.

If it is turned off, preset themes are ignored and only your own custom CSS can be used.

### Content script toggle

The options page also includes a content script enable/disable toggle.

Use this if you need to temporarily disable the main content features because of a conflict with another extension or while troubleshooting. This is useful if you want to keep the theme engine available while turning off other site interaction features.

---

## Forum theme editor

The forum theme editor is where you save styling per forum.

### Forum key

Each forum on Boards.ie has a unique slug in its URL. That slug becomes the forum key.

Examples:

```text
https://www.boards.ie/categories/after-hours      -> after-hours
https://www.boards.ie/categories/work-jobs        -> work-jobs
https://www.boards.ie/categories/soccer           -> soccer
https://www.boards.ie/categories/teach-na-ngealt  -> teach-na-ngealt
```

Enter that key in the **Forum key** field when creating or editing a theme.

### Enable this forum theme

Turn this on to enable theming for that specific forum key.

### Preset

Choose a built-in preset if you want to start from an existing theme.

### Custom CSS

Paste your own CSS here to style the selected forum. Custom CSS can be used on its own or together with a preset.

### Load forum config

Loads an existing saved config for the entered forum key.

### Save forum config

Saves the current enabled state, preset selection, and custom CSS for the current forum key.

### Delete forum config

Removes the saved settings for that forum key.

### Insert sample CSS

Inserts a starter CSS snippet for the selected forum key.

## How the theme engine works

When you visit a Boards.ie page, the theme engine:

1. Detects which forum you are on
2. Looks up any saved config for that forum key
3. Loads a preset theme if one is selected and presets are enabled globally
4. Injects your custom CSS if present
5. Applies a scoped class so the theme only affects that forum

This allows one forum to use a preset, another to use fully custom CSS, and another to remain unchanged.

## Writing custom CSS

Custom CSS must be scoped to the forum class generated by the theme engine.

Example:

```css
html.boards-theme-after-hours .postbit-header {
  background: linear-gradient(180deg, #5a3824 0%, #3b2418 100%) !important;
  color: #f4e9db !important;
}

html.boards-theme-after-hours .postbit-header a {
  color: #f4e9db !important;
}
```

Replace `after-hours` with the forum key you want to target.

### Important rule

Always scope your CSS to the forum class. Do not write global selectors unless you intentionally want to affect the whole Boards.ie site.

### Preset + custom CSS order

If both are used:

1. preset CSS loads first
2. custom CSS loads after it

That means your custom CSS wins where selectors conflict.

## Creating new presets

If you are developing the extension and want to add a new preset theme:

1. Create a new CSS file in `themes/presets/`
2. Add the preset entry in the theme engine mapping
3. Add the preset to the options page UI
4. Reload the extension and test it on the target forum

A template file may also be kept in `themes/templates/` for development use. For store packages, template files do not need to be included.

---

## Backup and restore

Boards.ie Cleaner supports exporting and importing theme settings.

### Export all themes

This creates a JSON backup containing:

- export date
- extension version
- global theme settings
- saved forum theme data

Use this before reinstalling, changing browsers, or making large edits.

### Import themes from file

This imports a previously exported JSON file.

Imported data is merged with your existing saved forum themes instead of wiping everything first, so partial restores are possible.

- `themes/presets/` - built-in preset CSS files
- `themes/templates/` - development templates and sample files

## Build and packaging

The PowerShell build script supports Chrome, Firefox, or both.

Example:

```powershell
.\build-boardscleaner.ps1 -Target both
```

It:

1. switches the active manifest
2. reads the version from `manifest.json`
3. creates release archives in `dist/`
4. restores the Chrome manifest afterwards for local development

For store-ready builds, it is good practice to exclude development-only files such as template files, PowerShell scripts, and scratch files from the packaged archive.

## Troubleshooting

### My theme is not applying

Check the following:

- global theming is enabled
- the forum key is correct
- the forum config is enabled
- preset themes are allowed globally if you are using a preset
- your custom CSS is scoped correctly
- the content script is not disabled if the feature you need depends on it

### My changes are not visible

Try:

- reloading the tab
- reloading the extension
- checking whether your selector is too weak
- adding `!important` where needed for Boards.ie overrides

### Another extension is interfering

Try disabling the content script toggle temporarily to narrow down the conflict, then re-enable it once testing is complete.

### I am reinstalling the extension

Export your themes first. Theme settings are stored in browser extension storage and may be lost if you remove the extension or clear browser data.

## Summary of use

For most users, the normal flow is:

1. Open options
2. Enable forum themes
3. Enter a forum key
4. Choose a preset or paste custom CSS
5. Save the forum config
6. Visit that forum on Boards.ie
7. Export your themes occasionally as backup
