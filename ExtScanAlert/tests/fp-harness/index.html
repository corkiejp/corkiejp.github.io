ExtScanAlert Fingerprint Harness

This page intentionally exercises common fingerprinting surfaces so you can verify detection hooks, source attribution, and event classification in a controlled environment. Common signals include canvas, WebGL, audio, fonts, screen, language, and timezone [web:116][web:118].

Canvas

Creates both a pre-existing canvas and a dynamic canvas, then reads pixels via toDataURL() and getImageData().

Includes a pre-rendered canvas because some detectors only watch dynamic creation paths [web:123][web:159].

WebGL

Queries renderer/vendor style parameters and selected capabilities from a WebGL context.

Audio

Uses an OfflineAudioContext render path, which is a common fingerprinting primitive [web:116][web:118].

Fonts

Measures text metrics across fallback stacks to infer font availability and rendering differences [web:118][web:120].

Navigator

Reads language, memory, concurrency, vendor, and related browser-exposed values.

Screen & time

Reads screen dimensions, pixel ratio, color depth, timezone, and locale formatting surfaces [web:118].
