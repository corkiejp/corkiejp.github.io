How to Use ATProto Record Viewer

  • Important Update: I have added the option to set the default presets on page/PWA load.
    You can also make a list of presets and import/export them. Handy to create them on One device and load in another. If you export a few different lists, you can create categorize sets of list to load.
    With the above your no longer forced to load my profile, sorry for not implementing it sooner, mainly creating this for my own use.
    Also added the option to view the latest 100 likes, so you can like a post and easily find it again with this.
    See my announcement : - Bluesky thread.
  • I have added the feature to display your (or any account) follows, limitation to the max of latest 100 records. Just select the option to switch to this in select drop-down after the collection field. Limitations of static html and the records you can pull from the PDS servers. See: - Bluesky thread.
  • Flexible URL Parameters:
    • Pass parameters to the HTML file, e.g.: ?pds=nameofpds&repo=did:plc:exampledid&collection=app.bsky.feed.post
    • Alternatively, use ?did= with your DID string-the script will auto-detect the PDS host.
    • Or use ?uri= to auto-detect and load the record by AT URI.
  • Smart Entry Detection:
    • Paste your repo/DID/URI and simply tab out or click away-no need to press return!
  • Where to Find Your Info:
    • Enable developer mode in the Bluesky app or website (long-press the version number) to get your DID and URI links.
  • Selective Content Display:
    • The viewer displays only public content, some media not available on static html.
    • Want to see the raw records? Click here for raw data view.
  • Limitations:
    • Some content may not display due to static HTML page restrictions. Learn more in this Bluesky thread.
  • Deep Links & Utilities:
    • Quick access to atp.Tools, SkyThread, and pdsls for every record.
    • Copy Links: Easily copy AT URI links and Bluesky permalinks for sharing or reference.

Tip: For the best experience, use the latest version of your browser.
