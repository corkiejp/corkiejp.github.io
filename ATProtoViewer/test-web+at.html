Key Points from Current Platform Support Desktop Chrome/Edge: Protocol handlers registered via the manifest work as expected. Android Chrome: As of now, protocol handler support via the manifest (protocol_handlers) is not implemented or not functional on Android Chrome. Even with a correct manifest, clicking a web+at: link on Android will not launch the installed PWA. Other Android browsers: The situation is the same or worse—PWAs generally do not get protocol handler support via the manifest on mobile browsers. iOS: Protocol handler support for PWAs is not available.
